# Руководство по тестированию банковского терминала

## Обзор

Данное руководство описывает комплексную систему тестирования банковского терминала, которая покрывает все слои архитектуры от HTTP-запросов до взаимодействия с Go-бинарём.

## Архитектура тестирования

### Слои тестирования

```
┌─────────────────────────────────────────────────────────────┐
│                    Интеграционные тесты                    │
│              (полный путь от HTTP до результата)           │
├─────────────────────────────────────────────────────────────┤
│                 Тесты интеграции с Go                      │
│              (взаимодействие с Go-бинарём)                │
├─────────────────────────────────────────────────────────────┤
│                     Unit тесты                             │
│              (отдельные компоненты)                       │
└─────────────────────────────────────────────────────────────┘
```

### Компоненты тестирования

1. **BankTerminalIntegrationTest** - Интеграционные тесты
2. **BankTerminalGoIntegrationTest** - Тесты интеграции с Go-бинарём
3. **Unit тесты** - Тесты отдельных компонентов

## Запуск тестов

### Запуск всех тестов

```bash
php tests/integration/run_bank_terminal_tests.php
```

### Запуск конкретных тестовых наборов

```bash
# Только интеграционные тесты
php tests/integration/run_bank_terminal_tests.php --integration

# Только тесты интеграции с Go-бинарём
php tests/integration/run_bank_terminal_tests.php --go-integration

# Справка по использованию
php tests/integration/run_bank_terminal_tests.php --help
```

## Детальное описание тестов

### 1. Интеграционные тесты (BankTerminalIntegrationTest)

Тестирует полный путь от HTTP-запроса до результата через все слои архитектуры.

#### Тестируемые сценарии:

- ✅ **Успешная оплата** - проверка полного цикла оплаты
- ✅ **Успешный возврат** - проверка полного цикла возврата
- ✅ **Успешная отмена** - проверка полного цикла отмены
- ✅ **Закрытие смены** - проверка закрытия смены терминала
- ✅ **Валидация отрицательной суммы** - проверка отклонения отрицательных сумм
- ✅ **Валидация нулевой суммы** - проверка отклонения нулевых сумм
- ✅ **Валидация некорректной операции** - проверка отклонения неверных операций
- ✅ **Поддержка legacy API** - проверка совместимости со старым API
- ✅ **Проверка здоровья** - проверка состояния банковского терминала

#### Пример теста:

```php
public function testSuccessfulPaymentFlow(): bool
{
    // Arrange: подготавливаем запрос
    $request = [
        'operation' => 'pay',
        'amount' => 150.75
    ];
    
    // Act: выполняем операцию через контроллер
    ob_start();
    $this->controller->handle($request);
    $response = ob_get_clean();
    
    // Assert: проверяем результат
    $responseData = json_decode($response, true);
    if (!isset($responseData['success']) || !$responseData['success']) {
        throw new \Exception('Оплата должна быть успешной');
    }
    
    return true;
}
```

### 2. Тесты интеграции с Go-бинарём (BankTerminalGoIntegrationTest)

Тестирует взаимодействие с Go-программой на низком уровне.

#### Тестируемые компоненты:

- ✅ **Создание временной директории** - проверка создания временных папок
- ✅ **Запись параметров операции** - проверка записи параметров в файлы
- ✅ **Выполнение Go-бинарня** - проверка запуска Go-программы
- ✅ **Ожидание результата** - проверка ожидания ответа от Go-программы
- ✅ **Очистка временных файлов** - проверка удаления временных файлов
- ✅ **Парсинг результата** - проверка обработки ответа от Go-программы
- ✅ **Обработка слипа** - проверка обработки банковского слипа
- ✅ **Режим эмуляции** - проверка работы в режиме эмуляции
- ✅ **Обработка ошибок** - проверка обработки ошибок от Go-программы

#### Пример теста:

```php
public function testTempDirectoryCreation(): bool
{
    // Используем reflection для доступа к приватному методу
    $reflection = new \ReflectionClass($this->adapter);
    $method = $reflection->getMethod('createTempDirectory');
    $method->setAccessible(true);
    
    // Act: создаем временную директорию
    $tempDir = $method->invoke($this->adapter);
    
    // Assert: проверяем результат
    if (!is_dir($tempDir)) {
        throw new \Exception('Временная директория должна быть создана');
    }
    
    return true;
}

## Конфигурация тестирования

### Настройки для тестов

Тесты используют настройки из `config/settings.json`:

```json
{
  "bank": {
    "task_name": "BankOperationTask",
    "timeout": 30,
    "emulation": false
  }
}
```

### Логирование тестов

Тесты создают отдельные лог-файлы:

- `logs/bank_test.log` - логи интеграционных тестов
- `logs/bank_go_test.log` - логи тестов интеграции с Go

## Рекомендации по тестированию

### 1. Регулярное тестирование

- Запускайте полный набор тестов перед каждым релизом
- Выполняйте тесты производительности при изменении конфигурации
- Мониторьте время выполнения операций

### 2. Тестирование в разных окружениях

- Тестируйте в режиме эмуляции для разработки
- Тестируйте с реальным Go-бинарём для продакшена
- Проверяйте работу в разных операционных системах

### 3. Мониторинг производительности

- Отслеживайте время выполнения операций
- Мониторьте использование памяти
- Контролируйте стабильность времени отклика

### 4. Обработка ошибок

- Тестируйте все возможные сценарии ошибок
- Проверяйте корректность сообщений об ошибках
- Убедитесь в правильной очистке ресурсов

## Устранение неполадок

### Частые проблемы

1. **Go-бинарнь не найден**
   - Проверьте путь в настройках
   - Убедитесь что файл существует и доступен для выполнения

2. **Тесты падают из-за таймаутов**
   - Увеличьте timeout в настройках
   - Проверьте состояние банковского терминала

3. **Ошибки валидации**
   - Проверьте корректность входных данных
   - Убедитесь в правильности формата запросов

4. **Проблемы с производительностью**
   - Проверьте нагрузку на систему
   - Мониторьте ресурсы сервера

### Отладка тестов

Для отладки тестов используйте:

```php
// Включение детального логирования
$this->logger->setLogLevel(LoggerInterface::DEBUG);

// Вывод дополнительной информации
echo "Debug: " . json_encode($responseData) . "\n";
```
