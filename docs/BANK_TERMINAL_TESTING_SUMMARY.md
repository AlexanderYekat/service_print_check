## Покрытие тестирования

- ✅ **API Layer** - Контроллеры и валидация запросов
- ✅ **Domain Layer** - UseCase и бизнес-логика
- ✅ **Infrastructure Layer** - Адаптеры и внешние сервисы
- ✅ **External Layer** - Go-бинарнь и банковский терминал

### Типы тестирования:
- ✅ **Unit Tests** - Тестирование отдельных компонентов
- ✅ **Integration Tests** - Тестирование взаимодействия компонентов

## Команды для запуска

```bash
# Запуск всех тестов
php tests/integration/run_bank_terminal_tests.php

# Запуск конкретных тестовых наборов
php tests/integration/run_bank_terminal_tests.php --integration
php tests/integration/run_bank_terminal_tests.php --go-integration

# Справка
php tests/integration/run_bank_terminal_tests.php --help
```

## Ключевые особенности

### 1. Полное покрытие архитектуры
- Тестирование всех слоев от HTTP до банковского терминала
- Проверка всех типов операций (pay, refund, cancel, close_shift)
- Валидация входных данных и обработка ошибок

### 2. Режим эмуляции
- Поддержка тестирования без реального банковского терминала
- Сохранение проверки работы с реальным оборудованием
- Логирование всех ошибок подключения

### 3. Совместимость
- Поддержка legacy API
- Обратная совместимость со старыми форматами запросов
