# Категории товаров для маркировки

## Обязательность категории

**Категория товара является обязательным полем для всех маркированных товаров.** При отправке данных чека через API `/api/print-check`, в каждом элементе `tableData` с маркированным товаром необходимо указать поле `category`.

## Поддерживаемые категории товаров

### 1. Молочные продукты
- **Код категории**: `dairy`
- **Описание**: Молочная продукция, подлежащая обязательной маркировке

### 2. Газированные напитки, соки, компоты, упакованная вода
- **Код категории**: `beverages`
- **Описание**: Безалкогольные напитки, соки, компоты и упакованная вода

### 3. Консервы (рыбные, мясные, овощные)
- **Код категории**: `canned_food`
- **Описание**: Консервированные продукты, упакованные в потребительскую упаковку

### 4. Растительные масла
- **Код категории**: `vegetable_oils`
- **Описание**: Пищевые растительные масла и масложировая продукция

### 5. Морепродукты (икра)
- **Код категории**: `seafood_caviar`
- **Описание**: Икра осетровых и икра лососевых (красная икра)

## Использование в API

При отправке данных чека через API `/api/print-check`, в каждом элементе `tableData` с маркированным товаром обязательно указывайте поле `category`:

```json
{
  "tableData": [
    {
      "name": "Молоко 3.2%",
      "quantity": 1,
      "price": 50.00,
      "taxNDS": "vat20",
      "category": "dairy",
      "markingCode": "01046040600017\u001d21ABC123"
    },
    {
      "name": "Сок яблочный",
      "quantity": 2,
      "price": 80.00,
      "taxNDS": "vat20",
      "category": "beverages",
      "markingCode": "01046040600017\u001d21XYZ789"
    },
    {
      "name": "Товар без маркировки",
      "quantity": 1,
      "price": 100.00,
      "taxNDS": "vat20"
      // category не требуется для товаров без маркировки
    }
  ]
}
```

## Обработка ошибок

- Если для маркированного товара не указана категория, система вернет ошибку
- Если указана неизвестная категория, система автоматически использует значения по умолчанию и залогирует предупреждение
- Для товаров без маркировки поле `category` не требуется

## Логирование

Система автоматически логирует информацию о выбранной категории и соответствующих документах на уровне DEBUG для отладки.
