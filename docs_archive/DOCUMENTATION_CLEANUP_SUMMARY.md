## 📋 Рекомендации по поддержке

### ✅ Что делать при добавлении новых документов
1. Размещать в соответствующей подпапке `docs/`
2. Обновлять навигационные ссылки в `docs/README.md`
3. Следовать единому стилю оформления
4. Добавлять эмодзи для лучшей навигации

1. Не создавать документы в корне проекта
2. Не дублировать информацию из README
3. Не размещать временные заметки в `docs/`
4. Не забывать обновлять ссылки при переименовании
