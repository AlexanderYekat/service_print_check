# 🚀 Быстрый старт тестирования

## За 3 шага к тестированию

### Шаг 1: Запустите сервис
```bash
# Убедитесь, что сервис запущен на порту 8000
http://localhost:8000
```

### Шаг 2: Откройте панель тестов
Откройте в браузере:
```
tests/test_plan_index.html
```

### Шаг 3: Выберите нужный тест
Кликните на карточку нужного теста и следуйте инструкциям.

## ⚡ Типовые задачи

### Напечатать простой чек
1. Откройте **Тест 1**
2. Нажмите "🛒 Продукты (3 позиции)"
3. Нажмите "🖨️ Печать чека"

### Проверить марку
1. Откройте **Тест 5**
2. Выберите марку (кнопки "Марка 1", "Марка 2", ...)
3. Нажмите "⚡ Обе проверки"

### Напечатать чек с 10 марками
1. Откройте **Тест 4**
2. Нажмите "🥛 Молоко (10 марок)"
3. Нажмите "🔍 Проверить все марки" (опционально)
4. Нажмите "🖨️ Печать чека"

### Проверить 100 чеков подряд
1. Откройте **Тест 3**
2. Установите "Количество чеков: 100"
3. Нажмите "▶️ Запустить тест"
4. Наблюдайте за прогрессом

## ❓ Частые вопросы

**Q: Где я вижу результат?**  
A: Внизу страницы появится зеленый (успех) или красный (ошибка) блок с результатом.

**Q: Что делать если ошибка?**  
A: Проверьте, что сервис запущен. Откройте http://localhost:8000 в браузере - должна открыться главная страница.

**Q: Откуда берутся марки?**  
A: Из файла `marks/test-marks.csv` - это 300 реальных марок молочной продукции.

**Q: Можно ли изменить данные?**  
A: Да, на большинстве страниц есть поля для ввода своих данных.

**Q: Как остановить массовый тест?**  
A: Нажмите кнопку "⏹️ Остановить".
