# 🧪 План тестирования системы печати чеков

## Быстрый старт

Откройте файл `test_plan_index.html` в браузере для доступа ко всем тестам.

## Описание тестов

### Тест 1: Обычный чек (`test_plan_1_regular_check.html`)
**Цель:** Проверить базовую функциональность печати обычных чеков без маркировки.

**Готовые сценарии:**
- 🛒 Продукты (3 позиции) - простой чек с продуктами
- 🍕 Кафе (5 позиций) - чек кафе/ресторана
- 📚 Книги (2 позиции) - чек книжного магазина
- 💳 Безнал (4 позиции) - оплата картой
- 💰 Смешанная оплата - наличные + карта

**Что проверяем:**
- Оплата наличными
- Оплата картой
- Смешанная оплата
- Корректность расчета сумм

---

### Тест 2: Большое количество позиций (`test_plan_2_many_items.html`)
**Цель:** Проверить работу системы с чеками, содержащими большое количество позиций.

**Возможности:**
- Генерация 20, 50, 100, 200, 500 позиций
- Произвольное количество позиций
- Автоматический расчет итоговой суммы
- Измерение времени обработки

**Что проверяем:**
- Производительность системы
- Корректность расчета при большом количестве позиций
- Стабильность работы
- Время обработки

---

### Тест 3: Много чеков подряд (`test_plan_3_many_checks.html`)
**Цель:** Проверить стабильность работы при печати большого количества чеков подряд.

**Параметры:**
- Количество чеков: 1-1000
- Позиций в каждом чеке: 1-100
- Задержка между чеками: 0-10000 мс

**Статистика:**
- Количество успешных/неудачных чеков
- Среднее время обработки
- Прогресс выполнения
- Подробный журнал

**Что проверяем:**
- Непрерывная работа
- Стабильность без сбоев
- Утечки памяти
- Обработка ошибок

---

### Тест 4: Марки и категории (`test_plan_4_marks_categories.html`)
**Цель:** Проверить работу с маркированными товарами.

**Готовые сценарии:**
- 🥛 Молоко (3, 10, 20, 50 марок)
- 🛒 Смешанный чек (маркированные + обычные товары)

**Возможности:**
- Проверка марок через ККТ
- Проверка через разрешительный режим
- Просмотр результатов проверки
- Массовая проверка всех марок

**Что проверяем:**
- Печать чеков с марками
- Интеграция с ККТ
- Интеграция с разрешительным режимом
- Обработка результатов проверки
- Смешанные чеки

---

### Тест 5: Проверка марок (`test_plan_5_mark_check.html`)
**Цель:** Проверить функции проверки маркировочных кодов.

**Режимы работы:**

#### Одиночная проверка
- Проверка через ККТ
- Проверка через разрешительный режим
- Обе проверки одновременно
- Быстрый выбор марки из списка (15 марок)

#### Массовая проверка
- Загрузка 5, 10, 20, 50 марок
- Выбор типа проверки (ККТ / Разрешение / Обе)
- Настройка задержки между проверками
- Статистика выполнения
- Подробные результаты

**Что проверяем:**
- API проверки марок через ККТ
- API проверки марок через разрешительный режим
- Обработка ошибок
- Производительность

## Советы по тестированию

1. **Начните с простого** - сначала тест 1, потом остальные
2. **Проверяйте логи** - смотрите результаты каждого теста
3. **Увеличивайте нагрузку постепенно** - 10 → 50 → 100 → 500
4. **Тестируйте марки перед печатью** - используйте тест 5
5. **Очищайте результаты** - кнопка "Очистить результат"

## Устранение неполадок

### Ошибка подключения
- Проверьте, что сервис запущен на порту 8000
- Проверьте настройки CORS
- Откройте консоль браузера (F12)

### Марки не проверяются
- Проверьте настройки ККТ
- Проверьте доступ к серверу маркировки
- Проверьте формат марки

### Медленная работа
- Уменьшите количество позиций/чеков
- Увеличьте задержку между запросами
- Проверьте нагрузку на систему
