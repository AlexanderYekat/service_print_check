📋 О плане тестирования

Набор тестов для комплексной проверки работы системы печати чеков с ККТ. Все тесты разработаны согласно плану тестирования и покрывают основные сценарии использования.

Основные сценарии:
  • ✅ Обычные чеки без маркировки
  • 📦 Чеки с большим количеством позиций
  • 🔄 Массовая печать чеков
  • 🏷️ Работа с маркированными товарами
  • 🔍 Проверка маркировочных кодов

Тесты согласно плану

01
📝 Обычный чек
Базовая функциональность печати чеков:
  • Наличная оплата
  • Безналичная оплата
  • Смешанная оплата
  • Различные категории товаров
02
📦 Большое количество позиций
Тестирование производительности:
  • 20, 50, 100+ позиций
  • Расчет итоговой суммы
  • Время обработки
  • Корректность печати
03
🔄 Много чеков подряд
Стресс-тестирование:
  • 10, 50, 100+ чеков
  • Стабильность работы
  • Статистика выполнения
  • Обработка ошибок
04
🏷️ Марки и категории
Работа с маркировкой:
  • Чеки с марками (3-50 шт.)
  • Проверка через ККТ
  • Проверка разрешений
  • Смешанные чеки
05
🔍 Проверка марок
Функции проверки кодов:
  • Одиночная проверка
  • Массовая проверка
  • ККТ и разрешения
  • Обработка ошибок
